## ggmosaic 0.3.4

- updated for compatibility with ggplot2 3.5.0

## ggmosaic 0.3.3

CRAN release: 2021-02-23

- A geom,
  [`geom_mosaic_jitter()`](https://haleyjeppson.github.io/ggmosaic/reference/geom_mosaic_jitter.md),
  and an associated stat,
  [`stat_mosaic_jitter()`](https://haleyjeppson.github.io/ggmosaic/reference/geom_mosaic_jitter.md),
  has been added.

- A geom,
  [`geom_mosaic_text()`](https://haleyjeppson.github.io/ggmosaic/reference/geom_mosaic_text.md),
  and an associated stat,
  [`stat_mosaic_text()`](https://haleyjeppson.github.io/ggmosaic/reference/geom_mosaic.md),
  has been added.

- [`geom_mosaic_text()`](https://haleyjeppson.github.io/ggmosaic/reference/geom_mosaic_text.md)
  now supports using labels and ggrepel
  ([@gregeleu](https://github.com/gregeleu),
  [\#50](https://github.com/haleyjeppson/ggmosaic/issues/50)).

- A theme for mosaic plots,
  [`theme_mosaic()`](https://haleyjeppson.github.io/ggmosaic/reference/theme_mosaic.md),
  has been added.

## ggmosaic 0.3.0

### Breaking changes

- ggmosaic 0.3.0 is now compatible with ggplot2 3.3.0 and tidyr 1.0.0.
