# Passengers and crew on board the Titanic

A dataset containing some demographics and survival of people on board
the Titanic

## Usage

``` r
titanic
```

## Format

A data frame with 2201 rows and 4 variables:

- Class:

  factor variable containing the class of a passenger (1st, 2nd, 3rd) or
  crew.

- Sex:

  Male/Female.

- Age:

  Child/Adult. This information is not very reliable, because it was
  inferred from boarding documents that did not state actual age in
  years.

- Survived:

  Yes/No.
